## Description

This project is a feedback modal built using HTML, CSS, and JavaScript.
It allows users to give a rating from 1 to 10 and submit their feedback in a simple and clean UI design.

The modal is centered on the screen and appears over a full-screen overlay background. 



## Features

* Modal popup overlay
* Rating system from 1 to 10
* Clean and modern UI design
* Close button functionality
* Responsive design for all devices
* Built with pure HTML, CSS, and JavaScript
